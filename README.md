# Java DSA Preparation

A repository dedicated to practicing **Data Structures and Algorithms (DSA) using Java**.

The main purpose of this repository is to strengthen problem-solving skills, understand DSA concepts, and build a strong foundation through regular practice.

## About

This repository contains the **class questions and practice problems** that I solve while learning DSA in Java.

The code is organized topic-wise to make it easier to understand, practice, and revisit different concepts.
